# РАСговорилка

Коммуникатор для детей с РАС. Помогает составлять фразы из карточек, озвучивать их и учиться говорить.

🗣️ Сказать

Основной режим. Собирает фразу из карточек с картинками или эмодзи, а приложение озвучивает её голосом.

📖 Автосклонение по падежам

Это то, что отличает «РАСговорилку» от обычных карточек-коммуникаторов.

Можно вручную задать падежные формы для любого слова или полностью отключить автосклонение в настройках.

То что нужно дорабатывать.

📝 Написать

Ввод текста с клавиатуры с той же озвучкой.

📚 Обучение

Четыре развивающих активности:

Викторина — (картинка → слово) или наоборот (слово → картинка)

Угадайка — Текстом по картинке, приложение проверяет

Сортировка — разложить карточки по категориям (еда / животные / транспорт)

Математика — сложение, вычитание, умножение, деление. Два режима ввода: перетаскивание или ручной ввод

🎮 Игры

Мемори — найди пары одинаковых карточек

Пятнашки — классическая числовая головоломка

Все активности настраиваются/отключаются: количество вопросов, категории, уровень сложности.

👍 Да / Нет

Быстрые кнопки для мгновенных ответов: да, нет, спасибо, хочу и т.д.

📅 Расписание

Визуальное расписание дня с шаблонами «Будний день» и «Выходной». Можно создавать свои шаблоны и привязывать их к дням недели.

(Но планирую это убирать, так как не очень удобно что это в приложении)

👤 Профили

Отдельные наборы данных для разных ситуаций: дома, в школе, у бабушки. У каждого профиля — свои категории, карточки, быстрые кнопки. Переключение — в один тап.

🖼️ Свои карточки

Любую карточку можно заменить на свою: загрузить фото реального предмета.

📦 Экспорт и импорт

Резервная копия всех данных в один файл .rasbackup. Полезно при смене устройства или чтобы поделиться профилем.

✨ Ключевые особенности

🆓 Полностью бесплатно и всегда таким будет

🔓 Открытый исходный код (GPL-3.0) — можно изучить, изменить, улучшить

🌐 Работает офлайн — интернет не нужен после установки

🚫 Без рекламы, без встроенных покупок, без сбора данных

📱 PWA — устанавливается на телефон, планшет, ПК как обычное приложение

🎨 Настраивается (долгий тап по иконке профиля переход в режим настройки, верхний правый угол) — карточки, категории, нужные/не нужные режимы


## Технологии

- Vanilla JavaScript (ES modules)
- Vite
- IndexedDB (через `idb`)
- Web Speech API (синтез речи)
- JSZip
