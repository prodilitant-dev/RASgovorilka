**РАСговорилка** — бесплатный коммуникатор для детей с РАС. Помогает детям с расстройствами аутистического спектра общаться: собирать фразы из карточек и озвучивать их в приложении. Приложение также помогает родителям лучше понимать своего ребёнка.

🌐 Это веб-приложение (PWA). Работает прямо в браузере и устанавливается на телефон или планшет как обычное приложение. Скачивать из магазинов ничего не нужно.

⚠️ Тестирование проводилось только на Android. На iPhone — не тестировалось.

## ✨ Ключевые особенности

- 🆓 Полностью бесплатно и всегда таким будет
- 🔓 Открытый исходный код (GPL-3.0)
- 🌐 Работает офлайн — интернет не нужен после установки
- 🚫 Без рекламы, без встроенных покупок, без сбора данных
- 📱 PWA — устанавливается на телефон или планшет как обычное приложение
- 🎨 Настраивается под ребёнка — свои карточки, свои категории, свой голос
- 🗣️ Голос для озвучки берётся из установленных в системе. Если нужного нет — можно доустановить в настройках телефона (например, «Речь» / Google TTS на Android).

## 🛠️ Технологии

- Vanilla JavaScript (ES modules)
- Vite
- IndexedDB (через `idb`)
- Web Speech API (синтез речи)
- JSZip
