# РАСговорилка

Коммуникатор для детей с РАС. Помогает составлять фразы из карточек, озвучивать их и учиться говорить.

## Возможности

- 🗣️ **Сказать** — составление фраз из карточек с автосклонением
- 📝 **Написать** — ввод текста с озвучкой
- 📚 **Обучение** — викторина, угадайка, сортировка, математика
- 🎮 **Игры** — мемори, пятнашки
- 👍 **Да/Нет** — быстрые ответы
- 📅 **Расписание** — режим дня с шаблонами
- 👤 **Профили** — отдельные наборы для разных ситуаций
- 📦 **Импорт/экспорт** — резервные копии в формате `.rasbackup`

## Технологии

- Vanilla JavaScript (ES modules)
- Vite
- IndexedDB (через `idb`)
- Web Speech API (синтез речи)
- JSZip
